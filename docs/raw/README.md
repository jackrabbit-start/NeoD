# NeoD Raw Sources

This directory is the landing page for the raw-source layer of the NeoD docs system.

## What belongs in the raw layer

- immutable source notes
- externally-derived research artifacts
- snapshots imported from outside the maintained wiki
- source-of-truth materials that should be synthesized, not continuously rewritten

## Current NeoD raw source references

- [README.md](../README.md)
- [AGENTS.md](../AGENTS.md)
- [.omx/specs/](../.omx/specs)
- [.omx/context/](../.omx/context)
- external references such as the Karpathy LLM wiki gist used to shape this docs layout

## Rule

Treat raw sources as inputs. Put living synthesized documentation in `docs/wiki/` instead.
